AWS Cloud Infrastructure — V1 → V2

A Terraform-managed AWS infrastructure project that evolved from a single EC2 web server into a highly available, load-balanced architecture using multiple Availability Zones and an Auto Scaling Group.

Key Implementation Work

  • Built a custom VPC, public subnets, Internet Gateway, and route tables.
  • Deployed Amazon Linux 2023 and NGINX using Terraform and EC2 Launch Templates.
  • Configured an Application Load Balancer, target group, and health checks.
  • Implemented an Auto Scaling Group with a minimum of two instances and a maximum of three.
  • Used AWS Systems Manager instead of exposing SSH access to V2 application servers.
  • Implemented GitHub Actions CI/CD using GitHub OIDC and Systems Manager.
  • Added CloudWatch alarms for target health and Auto Scaling capacity.
  • Applied security improvements, including dedicated security groups and required IMDSv2 for EC2 instances.

Technologies: AWS, Terraform, Linux, Amazon Linux 2023, NGINX, EC2, VPC, ALB, Auto Scaling, IAM, Systems Manager, CloudWatch, GitHub Actions, GitHub OIDC, Bash
